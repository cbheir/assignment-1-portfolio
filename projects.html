SafeBrowse AI - Capstone

This is a browser extension I created to help users identify suspicious websites and activities. This extension educates users while allowing them to explore the various features available to them. For this project I was very determined to create accessibility features for dyslexic or colour blind users. It also has a speak-aloud feature. Please contact me if you're interested in exploring the extension!

Restaurant Management System - Database Systems

In this project my team and I created a restaurant management system. This site helped to facilitate the environment where users can book reservations and the staff could clock in and out. The features also included a page to see what was available on the menu on a specific night and to see who was on schedule.

Airline Booking System - Intro to Cloud Services

For this project, my team member and I created a cloud based airline booking system. With this system, users were able to book flights and seats. Features included access to view unavailable flights or seats as well.
